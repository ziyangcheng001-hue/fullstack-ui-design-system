# fullstack-ui-design-system

通用全栈 UI 设计系统、微交互动画规范与宣传型 PPT 提示词生成器。

## 简介

本项目提供了一套完整的 AI 提示词规范（Skill / System Prompt），旨在统一并提升 AI 在前端开发、UI/UX 设计、微动作动画实现以及结构化宣传型 PPT 生成时的质量与审美。

## 核心功能

* **视觉风格系统**：遵循 Material Design 3 / Google 现代简洁风格，规范色彩、留白、卡片几何及字体层级[cite: 1, 7]。
* **微交互与平滑动画**：包含动画响应时长、流畅的跨页平滑（Morph）过渡及连贯的章节进度指示器[cite: 1, 2]。
* **中文排版契约**：严格规范中文标点使用与行尾避空规则，消除孤行与乱标点现象[cite: 4, 10]。
* **宣传型 PPT 生成器**：内置约 30 页宣传型 PPT 的标准提示词模板与章节结构推荐[cite: 1]。
* **全栈实现契约**：约束 AI 输出具备完整事件响应、状态机与 API 契约的全栈可运行代码，拒绝静态假壳[cite: 9, 10]。

    目标受众：【独立开发者 / 普通用户 / 企业客户 / 投资人】
    核心目的：快速理解项目定义、解决的痛点、核心优势、使用方式及选择理由。

    内容要求：
    1. 从用户痛点开始，逐步引出解决方案，不要一上来堆功能。
    2. 重点介绍【核心产品或服务】，展示相关生态和辅助功能。
    3. 使用真实、可信的数据（价格、性能、规模、实际案例）。
    4. 每项重要功能至少使用 1 至 2 页详细介绍。
    5. 结尾包含品牌总结、行动指引与官方网站。
